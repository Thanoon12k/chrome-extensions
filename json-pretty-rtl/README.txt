JSON Pretty • RTL v1.1

Features
- Automatically opens local .json, .jsonl and .ndjson files in the pretty viewer.
- Cards, Reader, Table, Tree, Graph branches, and raw JSON views.
- RTL / LTR / Auto text direction.
- Search, collection selection, dark mode, drag-and-drop, and formatted download.
- New JSON-style extension icon.
- Works locally; your JSON stays on your device.

Install in Chrome
1. Extract this ZIP.
2. Open chrome://extensions
3. Turn on Developer mode.
4. Click Load unpacked and choose the json-pretty-rtl folder.
5. IMPORTANT: open the extension Details page and enable "Allow access to file URLs".

After step 5, opening a local .json/.jsonl/.ndjson file in Chrome automatically launches JSON Pretty • RTL.
