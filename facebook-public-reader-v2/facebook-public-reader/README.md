# Facebook Public Post Reader 2.0 — قارئ المنشورات العامة

## الجديد في 2.0
- تنظيف «عرض أقل» من نهاية النص، دون تغيير معلومات المنشور.
- حفظ تلقائي في تخزين الإضافة المحلي واستعادة عند فتح نفس الصفحة. لا يبدأ الجمع تلقائياً. الحفظ محلي وفق API الرسمية: https://developer.chrome.com/docs/extensions/reference/api/storage/
- استيراد JSON النسخة السابقة لنفس الصفحة، ودمج الرابط المتكرر مع الاحتفاظ بالنص الأطول. البيانات المستوردة تعتمد على دليل الجمهور المسجل في الملف ولا تعتبر تحققاً جديداً.
- استخراج الهاشتاغات والروابط النصية إلى حقول منفصلة.
- بحث في النص، ومعاينة أول 10 نتائج، وترتيب بالتاريخ. التصدير يشمل نتائج البحث فقط وبالترتيب المختار؛ امسح البحث لتصدير الجميع.
- تفسير التاريخ العربي الكامل مثل «14 سبتمبر 2025»؛ التواريخ النسبية أو غير المعروفة لا تُخمّن وتأتي أخيراً عند الترتيب.
- انتظار توسّع النص حتى 4 ثوانٍ في المحاولة، ومحاولات محدودة، وانتظار أطول عند بطء ظهور نتائج. يتوقف مؤقتاً إذا أصبح التبويب غير نشط.
- إحصاء أسباب التجاهل في آخر جولة؛ هي عدد فحوص وليست عدد منشورات فريدة.

## تحديث النسخة القديمة
احتفظ بنسخة ملفاتك القديمة. استبدل ملفات مجلد الإضافة السابق بمحتويات المجلد الجديد، ثم اضغط Reload في صفحة الإضافات. إذا طلب المتصفح الموافقة على صلاحية storage فهي للحفظ المحلي. حدّث صفحة Facebook ثم افتح الإضافة. اضغط «استيراد JSON سابق» واختر ملف النتائج الذي نزلته. حد المنشورات يشمل المستوردة والمحفوظة؛ ارفعه إذا أردت جمع المزيد. لا تحذف الإضافة القديمة قبل تصدير بياناتك؛ حذف الإضافة يحذف تخزينها المحلي.

إضافة محلية تجريبية لـ Chrome / Brave / Edge. لا تحتاج Python أو API أو كلمة مرور داخل الإضافة.

## التثبيت
1. فك ضغط الملف ZIP.
2. افتح chrome://extensions في Chrome، أو brave://extensions في Brave، أو edge://extensions في Edge.
3. فعّل Developer mode، واضغط Load unpacked.
4. اختر مجلد facebook-public-reader الذي يحتوي manifest.json.
5. افتح https://www.facebook.com/profile.php?id=61575969329229 وسجّل الدخول بنفسك إن احتجت.
6. افتح تبويب المنشورات، واضغط أيقونة الإضافة ثم «بدء / متابعة». اترك التبويب مفتوحاً ونشطاً ولا تنتقل إلى صفحة أخرى أثناء الجمع.
7. اضغط «إيقاف» ثم «تنزيل TXT» أو «تنزيل JSON». ارفع الناتج إلى ChatGPT لقراءته وتحليله.

## ما الذي تجمعه؟
- نص الرسالة الأساسية فقط، وليس نص التعليقات أو كامل بطاقة المنشور.
- تضغط See more / Show more / عرض المزيد / مشاهدة المزيد داخل النص الأساسي فقط.
- تمرّر الصفحة تدريجياً، وتزيل التكرار باستخدام رابط المنشور.
- تشترط علامة جمهور Public / عام / العامة في رأس المنشور قبل النص، ورابطاً للمنشور في الرأس. لا تعتمد على كلمة Public داخل نص المنشور.
- تتجاهل التصاميم أو الخصوصية غير المعروفة، حتى لو كان المنشور عاماً بالفعل. استخراج الجمهور قرينة من واجهة Facebook، وليس تحققاً مستقلاً من إمكانية فتح الرابط دون تسجيل دخول.
- تُصدّر رابط المنشور، دليل الجمهور، تسمية التاريخ المتاحة (قد تكون فارغة/نسبية)، النص، حالة التوسيع ووقت الجمع.

## حدود مهمة
هذه نسخة أولية؛ لم تختبر على جلسة Facebook حقيقية. قد تتطلب محددات DOM تعديلاً لتصميم حسابك. إذا خرجت صفر نتائج، فهذا لا يعني عدم وجود منشورات عامة. أرسل لقطة كاملة لرأس منشور ونصه (مع إخفاء معلوماتك الشخصية) لتشخيص السبب؛ لا ترسل Cookies أو Tokens.

لا ضمان لجمع «كل المنشورات»: التحميل اللانهائي، ترتيب الصفحة، وتغييرات Facebook قد تمنع ذلك. الأداة تتوقف بعد 15 جولة دون نتائج جديدة أو عند حد المنشورات، ولا تدعي اكتمال الأرشيف. يبدأ الجمع من موضع التمرير الحالي؛ ابدأ من أعلى تبويب المنشورات. لا تستخدم الصفحة الرئيسية أو المجموعات. قد تشمل الصفحة منشورات مثبتة/مقترحة إن عرضها Facebook كبطاقات عامة؛ راجع الروابط لتحديد الكاتب، فالأداة لا تتحقق من هوية المؤلف. النص الموجود داخل الصور والفيديوهات لا يُستخرج ولا يوجد OCR.

النتائج تحفظ محلياً بعد الجولات التي تضيف نصاً جديداً وعند التوقف والاستيراد. لا تفترض أن آخر جولة محفوظة قبل ظهور رسالة نجاح الحفظ. إذا فشل الحفظ (مثل بلوغ حصة التخزين) يظهر تنبيه داخل اللوحة؛ نزّل النتائج فوراً. فتح لوحة الإضافة لنفس الصفحة يستعيد البيانات، لكنه لا يستعيد موضع التمرير القديم. استخدم جلسة جمع واحدة للصفحة لتجنب تعارض الحفظ. يمكن تنزيل النتائج أثناء الجمع أيضاً.

## الخصوصية والاستخدام
الصلاحيات activeTab وscripting وstorage؛ لا صلاحية Cookies ولا خادم خارجي ولا إرسال بيانات. الحفظ في chrome.storage.local وليس في تخزين موقع Facebook. لا تضغط إعجاب/تعليق/مشاركة ولا تستعمل API خفية أو تتجاوز قيود الوصول. تسجيل الدخول يدوي في Facebook. إذا ظهر تحقق أوقف الأداة؛ لا تتجاوز الحظر. استخدمها فقط عندما يكون جمع المحتوى مسموحاً لك وبما يتفق مع شروط الموقع وحقوق المحتوى.

Chrome API documentation: https://developer.chrome.com/docs/extensions/reference/api/scripting

## الاختبار
نفّذ node tests.cjs لاختبار مطابقة الجمهور وأزرار التوسيع وتطبيع روابط المنشورات. هذه اختبارات منطقية وليست اختباراً حياً لتصميم Facebook.
